# Rock Paper Scissors

Rock Paper Scissors project for [The Odin Project](https://www.theodinproject.com/) curriculum.

## Live Demo

[Play the game here](https://ahmadziadev.github.io/rps/)

## About

This is a simple browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.
